## Installation
Install the required libraries using:

```bash
pip install opencv-python numpy matplotlib pillow scikit-image jupyter
```

## How to Run
1. Clone or download this repository.
2. Open the required practical folder.
3. Launch Jupyter Notebook.
4. Open the respective `.ipynb` file.
5. Ensure the required images are available in the same folder as the notebook.
6. Run the notebook cells in sequence.
